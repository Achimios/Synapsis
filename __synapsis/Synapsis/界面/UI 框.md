界面草稿用的特殊节点：空白处右键「▭ 新建 UI 框」。frontmatter ui: true + w / h；默认 220×140（刚建出来里面没东西，别太大），右下角拖大小。

- 默认展开子图：里面的东西画在框里，位置 = 钻进去那一页的坐标，包围盒中点对准框中点（展开那一刻定下，之后拖动不跟着跳）；加子节点走子图，不走子级列表；标题上有 ▸ N（子级列表）和 ⊞/⊟（子图），只认自己的状态，不跟竖栏的「预览展开」
- 选中展开子图的框（普通节点也一样）后，鼠标在框上滚轮 = 缩放框内的画布（0.3~3），不在框上照旧缩放整页；缩放不存盘
- 双击框里任何地方（不用点标题）钻进去，里面是正常画布，可放 UI 框或普通节点（写文字说明）

右键「复制 UI 布局」：每一级 UI 框输出四个角坐标 + 宽高，普通节点输出名字和正文前 120 字（core/uilayout.js）。

没做：命令行导出 UI 布局；缩放框本身不带动里面的东西（没有锚点）；框内缩放不存盘。
