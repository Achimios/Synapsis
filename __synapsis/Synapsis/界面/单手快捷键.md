👤 的思路：这些是基础操作，像打 FPS 游戏，左手一只手能完成；快捷键在输入文字时不触发。

- Alt+W/A/D：上一层 / 后退 / 前进；Alt+S：钻进去（没选中不管）
- WASD：跳到上下左右最近的卡
- Shift+A/D 沿入线 / 出线扩选一层，Alt+Shift+A/D 扩到头，Ctrl+A 全选画布节点
- 1 2 3 4 = 子图 / 子级 / 属性 / 正文：选中了就切这张卡自己的，没选中 = 本页「预览展开」
- Enter = 重命名（选中时）；Shift+Enter = 新建同级；没选中按 Enter 什么都不做（常误触，去掉了）；Ctrl+Enter / Insert 新建子级
- Shift+Tab 右栏属性、Shift+反引号 操作历史栏、Shift+F AI 指令框、Tab 左栏、Q 看清连线
- 双击只在标题行才钻进去（UI 框例外：框里任何地方双击都能进）

没做：键位自定义（要先把按键处理改成「动作名 → 键」一张表）。表在 core/keymap.js，界面 ? / F1 页同一份。
