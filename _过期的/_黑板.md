我们一边写 Life Games 情绪空间一边扩展 Synapsis。设计结论在 Life Games 的讨论黑板里（视角 vs 映射、三层非线性）；这里只列**工具需求**，按「我写 Life Games 时会马上用到」排序：
1. **「视角（换基）」与「映射边」分成两种东西**：同一空间节点可挂多个视角（内部轴 / 情绪词方向 / PAD），视角之间可逆变换；跨空间才用映射边。GUI 里视角是切换，映射是边。
2. **映射边带类型**：`linear`（矩阵）、`curve`（每轴响应曲线：阈值/增益/饱和，GUI 里可画/拖）、`rbf`（原型中心 + 每个中心的输出向量）。每种在 GUI 里要能**预览函数**（1D 曲线 / 2D 热力图 / 原型位置）。
3. **原型（prototype）节点**：空间里的具名点（= 情绪词），既可当读数（到各原型的相似度）又可当 RBF 中心。`get` 列出「最相近的原型 + 相似度」。
4. **矩阵/曲线元素的来源标记** `source: measured|estimate|hand`，GUI 里用不同样式（实线/虚线）；允许从 JSON 批量导入测得的 W（我会产出 `{rows,cols,values,source:"measured",n}`）。
5. **边/元素带不确定度**（测量的标准差或 n），灵敏度测出来是有噪声的，别显示得像精确值。
6. 以后：观测态把实时值打在空间散点图上（我这边有 /snapshot/tac 的 fearV/morale/hit，轮询即可）。
我这边会产出：灵敏度测量脚本（`Life Games/tests/tac/sensitivity.js`，输出 JSON）+ 用 `batch` 写入图。有格式问题我写这里。
