---
do: tighten
args: ids（≥2 个）, s（可选，0~1：距离变成原来的几成；不给 = 收到最紧但不挨着）, gap（可选，10~300，最紧时卡片之间留多宽，默认 40）
---
把卡片整体朝中间靠拢：谁在谁的左边 / 上边都不变（相对方位不变），只是彼此距离变近，只改位置。
「紧凑一点 / 收紧 / 靠近一点 / 太散了 / 整理一下但别改布局」都用它；人没说哪几个 → ids 填本页所有节点。反过来要排成一行 / 一列才用 arrange，要贴齐某条边才用 align。
例：「整页紧凑一点，方位别变」→ {"do":"tighten","ids":["n1","n2","n3","n4"]}
例：「这几个距离缩到一半」→ {"do":"tighten","ids":["n2","n5"],"s":0.5}
