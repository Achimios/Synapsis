---
do: remember
args: name（短名字，当文件名）, text（要记的内容）, level（可选：项目 = 只这个项目，默认 | 用户 = 所有项目都适用的、关于这个人的）, type（可选：user 关于这个人 | feedback 他纠正过或认可过的做法 | project 这个项目的事实和决定 | reference 去哪儿能查到）, desc（可选：索引里那一句描述）, mode（可选：append 接在后面，默认 | replace 整份换掉）
---
把以后还用得上的东西记进长期记忆：这个项目是干嘛的、约定、人的偏好、做过的决定和理由。人说「记住 / 以后都 / 别忘了」时用；你自己觉得值得记，也可以提议（人确认才写）。
别记当前页上已经有的东西，也别记一次性的小事。同一件事已经有记忆了就用同一个 name 接着写；和旧记忆矛盾了就用 replace 换掉，别让两条互相打架。
type 是 feedback（他纠正过你 / 认可过你的做法）时，text 写成：规则本身 + 一行「为什么」+ 一行「什么时候用」，以后才能判断边界情况。
例：「记住：这个项目的空间都按 观测→决策→行动 分层」→ {"do":"remember","name":"分层约定","type":"project","text":"空间按 观测 → 决策 → 行动 分层","desc":"空间的分层约定"}
