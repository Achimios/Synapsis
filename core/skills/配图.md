用 Grok 或豆包 Seedream 生成一张图，贴进这张卡（存进它的图片文件夹）；不写 id = 这一页的散图（人说散图 / 在这里画时）。要花钱，人确认后才生成。只在人要配图 / 画图时用。
看不出该画什么（卡片名 / 正文太含糊）就先问人，别瞎编。prompt 写清画面内容和风格（中英文都行）；aspect 看卡片用途选，不确定就 auto。
title = 简介：中文几个字说这张是什么（进文件名，如「波包穿过分层图像」）；about = 描述：一两句中文说画了什么、为什么这样画（存在图旁边的说明里，以后人和 AI 都靠它认图）。
quality / resolution / model 不写 = 人设的默认；人说要高质量才写 medium / 2k。人在确认时还能改 prompt 和参数。
