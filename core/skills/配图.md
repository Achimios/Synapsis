args: id（可省）, prompt, aspect = auto | 1:1 | 16:9 | 9:16 | 4:3 | 3:4 | 3:2 | 2:3 | 21:9, quality = low | medium（可省）, resolution = 1k | 2k（可省）, model = grok-imagine-image-2.0 | grok-imagine-image-quality（可省）

用 Grok 生成一张图，贴进这张卡（存进它的图片文件夹）；不写 id = 这一页的散图（人说散图 / 在这里画时）。要花钱，人确认后才生成。只在人要配图 / 画图时用。
看不出该画什么（卡片名 / 正文太含糊）就先问人，别瞎编。prompt 写清画面内容和风格（中英文都行）；aspect 看卡片用途选，不确定就 auto。
quality / resolution / model 不写 = 人设的默认；人说要高质量才写 medium / 2k。人在确认时还能改 prompt 和参数。
例：「给咕噜人配张图」→ {"do":"image","id":"n4","prompt":"a small hunched goblin scavenger in a dark cave, game concept art, painterly","aspect":"1:1"}
