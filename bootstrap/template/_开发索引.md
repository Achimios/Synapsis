# 开发索引表

代码里用 `>v<` 开头的注释做标记，方便直接 grep/glob 定位到具体功能，不用翻文件结构。

**格式**：`>v<[emoji]大标题-小标题-一句话注释`
例：`>v<🔋电压检测-S数检测-上电用空载电压猜电池串数，运行期不再变`

**怎么用**：想改哪块功能，先在本表找到大标题，再全局搜那个大标题字符串，
所有相关位置会一次性全列出来，跨文件也不会漏。

```bash
grep -rn ">v<🔋电压检测" .
```

> ⚠️ 在本文件里写标记一律包反引号 `` `>v<…` `` —— 行首的 `>` 会被 Markdown 当成引用块。
> 本表 {{DATE}} 开始建。以后每改一处就顺手加标记并在这里登记。
